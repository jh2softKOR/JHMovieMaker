6. 유튜브 자동 업로드

유튜브 업로드는 구글이 본인 확인을 거친 앱에서만 허용돼서, 본인 소유의 Google Cloud 프로젝트에서 발급받은 Client ID가 필요해요. Google Cloud Console에서 "OAuth 클라이언트 ID" (웹 애플리케이션)를 만들고, 승인된 JavaScript 원본에 이 페이지 주소를 추가한 뒤, YouTube Data API v3를 사용 설정해주세요.

중요: 이 파일을 그냥 더블클릭해서 열면(주소가 file://로 시작) 구글 로그인이 CORS 문제로 동작하지 않아요. 반드시 http:// 또는 https://로 서비스되는 주소에서 열어야 합니다 (예: 컴퓨터에서 간단한 로컬 서버를 띄우거나, 웹 호스팅에 올리기). 그 주소를 Google Cloud Console의 "승인된 JavaScript 원본"에도 등록해주세요.
